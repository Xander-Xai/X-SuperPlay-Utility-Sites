Calculation methodology

Weights (GiB) = number of parameters (billions × 10⁹) × ideal bits/parameter ÷ 8 ÷ 2³⁰.

KV cache (GiB) = 2 × layers × KV heads × head dimension × context tokens × concurrent sequences × (KV bits ÷ 8) ÷ 2³⁰. This assumes dense/full attention and uniform K/V cache across all layers.

Total capacity budget = weights + KV + overhead percentage × (weights + KV) + user-specified device reserve. GiB means 2³⁰ bytes; GB means 10⁹ bytes.

Weight bits represent ideal storage, not actual file size. Quantized GGUF uses scale/block metadata and may mix precisions. Model architecture may include sparse, sliding-window, recurrent, hybrid or latent attention; MoE weight and execution accounting differs. GPU/CPU offload, tensor parallelism, fragmentation, kernels, reserved CUDA memory and actual cache occupancy are not modeled.

Known limitation: real multi-GPU memory is not the sum of cards unless an explicitly configured parallel strategy supports it; this prototype models one GPU only. Always compare a real runtime load and telemetry before committing hardware or contracts.

For implementation evidence, the calculation is pure JavaScript with deterministic tests. Technical work is a research prototype, not third-party performance validation.
