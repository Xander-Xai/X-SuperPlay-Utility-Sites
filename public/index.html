    This is a deliberately simple dense full-attention / uniform GQA model. It ignores sliding-window, hybrid/recurrent, MoE, offload, tensor-parallel placement, runtime allocator behaviour and model-specific quant metadata. A passing estimate is never a fit guarantee.

    What this prototype can answer

    • How much theoretical weight memory a chosen precision consumes.
    • How KV memory scales with tokens, KV heads and concurrent sequences.
    • What assumptions cause different calculators to disagree.

    What it cannot answer

    • Whether a named GPU will run a real model or at what tokens per second.
    • Whether hybrid attention or quantized GGUF file size matches the ideal formula.
    • Whether GPU driver, framework or offload strategies change the actual result.
